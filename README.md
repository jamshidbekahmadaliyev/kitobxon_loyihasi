# KITOBXON

“Kitobni o‘qima. Undan fikr yarat.”

KITOBXON is a social reading platform for people who want to read, reflect, write, share, discuss, and learn.

## Tech Stack
- Next.js (App Router)
- Tailwind CSS
- LibSQL / Turso
- Drizzle ORM

## Local Setup

1. Clone the repo
2. Run npm install
3. Copy .env.example to .env
4. Run npx drizzle-kit push to create the local DB
5. Run npm run dev
